## Touchline

A complete, browser-playable football game built with plain HTML, CSS, and JavaScript. Open `index.html` directly or serve this directory with any static web server.

- Play 90-second friendly matches against adaptive opponents.
- Move with **WASD / arrow keys**, **Shift** to sprint, **Space** to pass or shoot, and **Q** to switch player.
- On touch screens, use the on-screen direction pad and action button (or tap and drag on the pitch).
- Track your season, earn coins from matches, and sign free agents. Better signings automatically enter your starting six; displaced players move to the bench.
- Career progress, results, squad, and wallet are saved in your browser.
